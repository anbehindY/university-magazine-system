2. **SubmissionComment model** — Add a self-referential relation for reply threading:
   - `parentId String? @map("parent_id")` — nullable FK to the same table
   - `parent SubmissionComment? @relation("CommentReplies", fields: [parentId], references: [id], onDelete: SetNull)` — optional parent
   - `replies SubmissionComment[] @relation("CommentReplies")` — child replies

The self-relation requires a named relation string `"CommentReplies"` with both sides declared. Use `onDelete: SetNull` so deleting a parent comment nullifies children rather than cascading.
