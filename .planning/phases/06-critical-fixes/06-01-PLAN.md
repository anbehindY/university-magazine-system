2. **Add state** for `finalClosureDate`:

3. **Derive `isPastFinalClosure`** from the state:

4. **Read `finalClosureDate` from the existing fetch response.** In the existing useEffect that fetches from `/api/manager/submissions`, after setting submissions and academicYears from the response data, add:


5. **Wrap each Download ZIP button** in a `TooltipProvider > Tooltip > TooltipTrigger > span > Button` structure. The button's `disabled` prop should be extended to include `!isPastFinalClosure`:
   ```tsx
   <TooltipProvider>
     <Tooltip>
       <TooltipTrigger asChild>
         <span tabIndex={0}>
           <Button
             size="sm"
             onClick={() => handleDownloadZip(yearId, label)}
             disabled={!isPastFinalClosure || downloadingYearId !== null}
             className="..."
           >
             {/* existing button content */}
           </Button>
         </span>
       </TooltipTrigger>
       {!isPastFinalClosure && (
         <TooltipContent>
           Available after{" "}
           {finalClosureDate

         </TooltipContent>
       )}
     </Tooltip>
   </TooltipProvider>
   ```

6. The `<span tabIndex={0}>` wrapper is required because disabled buttons do not fire mouse events in some browsers, preventing the Tooltip from showing.
