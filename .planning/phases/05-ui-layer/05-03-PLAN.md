Create `app/(management)/manager/submissions/page.tsx` as a `"use client"` page.

**Data loading:**
- Fetch `/api/manager/submissions` on mount (and re-fetch when faculty filter changes with `?facultyId=X`)
- Fetch `/api/faculties` on mount for the faculty dropdown options
- Fetch `/api/academic-years` on mount to get `finalClosureDate` for the download button disabled state
- Store in state: `submissions`, `faculties`, `finalClosureDate`, `selectedFacultyId`, `loading`, `error`

**Faculty filter (per locked decision):**
- `Select` component (from `components/ui/select.tsx`) at top of page with options: "All Faculties" (value: empty string) + one option per faculty from `/api/faculties`
- Changing the selection re-fetches `/api/manager/submissions?facultyId=X` (or no param for "All")
- Show total selected count badge next to the page title (e.g., "Selected Submissions (12)")
- Show per-faculty count badge next to the filter dropdown when a specific faculty is selected

**Submissions table:**
- Columns: Student Name, Title, Faculty, Submitted Date (formatted with `date-fns`), Files (count)
- Render a clean data table with existing Tailwind patterns
- No row click action (manager view is read-only per MGR-01)

**Download ZIP button (per locked decision):**
- Place a prominent "Download ZIP" button at the top of the page (near the filter)
- Disabled state: if `finalClosureDate` is null or `new Date(finalClosureDate) > new Date()`, disable the button
- When disabled, wrap in `Tooltip` (from `components/ui/tooltip.tsx`) with message "ZIP download is available after the final closure date"
- When enabled and clicked:
  1. Set `downloading` state to true (show spinner/loading text on button)
  2. `const res = await fetch("/api/manager/submissions/download")`
  3. If `!res.ok`: show error toast via `sonner` and return
  4. `const blob = await res.blob()`
  5. Create object URL, create temporary `<a>` element with `download="selected-submissions.zip"`, click it, revoke URL
  6. Set `downloading` to false in `finally` block
- Use `lucide-react` Download icon on the button

**Empty state:**
- When no selected submissions: "No submissions have been selected for publication yet"
