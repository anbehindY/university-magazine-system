Modify the existing `GET()` handler in `app/api/admin/users/route.ts` to accept `page` and `pageSize` query parameters and return paginated results with a total count.

Change the handler signature from `GET()` to `GET(req: NextRequest)`.

After the auth check, parse and validate query params:
```typescript
const { searchParams } = new URL(req.url);
const page = Math.max(1, parseInt(searchParams.get("page") ?? "1", 10) || 1);
const pageSize = (() => {
  const raw = parseInt(searchParams.get("pageSize") ?? "10", 10);
  return [10, 25, 50].includes(raw) ? raw : 10;
})();
const skip = (page - 1) * pageSize;
```

Replace the single `prisma.user.findMany()` call with a `Promise.all` running count and findMany in parallel:
```typescript
const [total, users] = await Promise.all([
  prisma.user.count(),
  prisma.user.findMany({
    skip,
    take: pageSize,
    orderBy: [{ createdAt: "desc" }, { id: "asc" }],
    select: { /* keep exact same select as before */ },
  }),
]);
```

Note: add `{ id: "asc" }` as tiebreaker to the orderBy array (was previously `{ createdAt: "desc" }` only). Keep all other select fields identical to avoid breaking anything.

```typescript
return NextResponse.json({ users: usersWithLastActive, total, page, pageSize }, { status: 200 });
```
