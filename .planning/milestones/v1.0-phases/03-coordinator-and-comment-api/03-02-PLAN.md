**Guard sequence (top of handler):**
1. Auth check: `auth.api.getSession({ headers: await headers() })` — return 401 if no session
2. Role check: `session.user.role !== "MARKETING_COORDINATOR"` — return 403
3. Faculty lookup: `prisma.user.findUnique({ where: { id: session.user.id }, select: { facultyId: true } })` — return 403 if `!dbUser?.facultyId` ("Coordinator has no assigned faculty")

**Query:**
```typescript
const submissions = await prisma.submission.findMany({
  where: {
    status: "SUBMITTED",
    facultyId: coordinatorFacultyId,
  },
  orderBy: { submittedAt: "desc" },
  select: {
    id: true,
    title: true,
    status: true,
    submittedAt: true,
    isSelected: true,
    notes: true,
    user: { select: { name: true } },
    _count: { select: { files: true } },
  },
});
```

Create `app/api/coordinator/submissions/[id]/route.ts` with a PATCH handler.

**Guard sequence:**
1. Auth check — return 401 if no session
2. Role check — return 403 if not MARKETING_COORDINATOR
3. Faculty lookup — return 403 if no assigned faculty
4. Final closure check: `if (await isPastFinalClosure())` — return 403 "Submissions are locked. The final closure date has passed."

**Extract `id` from route params:**
Use the Next.js App Router dynamic route pattern:
```typescript
export async function PATCH(
  req: NextRequest,
  { params }: { params: Promise<{ id: string }> }
) {
  const { id } = await params;
```

**Fetch and verify submission:**
```typescript
const submission = await prisma.submission.findUnique({
  where: { id },
  select: { facultyId: true },
});
if (!submission) {
  return NextResponse.json({ error: "Submission not found" }, { status: 404 });
}
if (submission.facultyId !== coordinatorFacultyId) {
  return NextResponse.json({ error: "Forbidden: submission belongs to a different faculty" }, { status: 403 });
}
```

**Build update data — only update fields present in body:**
```typescript
const body = await req.json();
const updateData: { isSelected?: boolean; notes?: string | null } = {};
if (typeof body.isSelected === "boolean") {
  updateData.isSelected = body.isSelected;
}
if (body.notes !== undefined) {
  updateData.notes = body.notes ?? null;
}
if (Object.keys(updateData).length === 0) {
  return NextResponse.json({ error: "No valid fields to update" }, { status: 400 });
}
```

**Execute update and return:**
```typescript
const updated = await prisma.submission.update({
  where: { id },
  data: updateData,
  select: { id: true, isSelected: true, notes: true },
});
return NextResponse.json({ submission: updated });
```

**Note:** Do NOT populate `selectedAt` or `selectedById` — those are v2 fields (AUDIT-V2-01).
