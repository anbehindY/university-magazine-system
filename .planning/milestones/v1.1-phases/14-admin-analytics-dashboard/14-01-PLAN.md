<task type="auto">
  <name>Task 1: Install dependencies and create analytics API endpoint</name>
  <files>package.json, app/api/admin/analytics/route.ts</files>
  <action>
1. Install runtime dependencies: `npm install recharts ua-parser-js`. Check if ua-parser-js v2 ships its own types -- if not, also `npm install -D @types/ua-parser-js`. Recharts v3 includes its own types.

2. Create `app/api/admin/analytics/route.ts` with a single GET handler:
   - Auth: `requireRole(["ADMINISTRATOR", "MARKETING_MANAGER"])` -- return 403 if unauthorized.
   - Active users query:
     - Compute `sevenDaysAgo` and `thirtyDaysAgo` from current date.
     - Fetch sessions from Prisma: `prisma.session.findMany({ where: { updatedAt: { gte: thirtyDaysAgo }, user: { banned: { not: true } } }, select: { userId: true, updatedAt: true } })`.
     - Compute `total7d` = count of distinct userIds where updatedAt >= sevenDaysAgo.
     - Compute `total30d` = count of distinct userIds from all fetched sessions.
     - Build daily cumulative array: For each day in the selected period (default 30 days), count distinct users with updatedAt on or before that day within the period. Use UTC dates formatted as `YYYY-MM-DD`. Do NOT run N+1 queries -- fetch all sessions once and compute in JS by iterating days and accumulating a Set of userIds.
   - Browser breakdown query:
     - Fetch all sessions with non-null userAgent: `prisma.session.findMany({ where: { userAgent: { not: null } }, select: { userAgent: true } })`.
     - For each session: check `isBot(userAgent)` from `ua-parser-js/helpers` -- skip bots. Parse with `new UAParser(userAgent).getBrowser()`. Use `browser.name || "Unknown"` as the key. Accumulate counts in a Record.
     - Apply 5% threshold: compute total count, any browser with count < total * 0.05 goes into "Other" bucket.
     - Return array of `{ name, count, percentage }` sorted by count descending.
   - Accept optional `period` query param ("7d" or "30d", default "30d") to control which daily array is returned.
   - Return JSON matching the response shape: `{ activeUsers: { total7d, total30d, daily }, browsers }`.
   - Wrap in try/catch, log errors with console.error, return 500 on failure.

Key pitfalls to avoid:
- Import `isBot` from `ua-parser-js/helpers` (NOT from main export -- v2 restructured imports).
- Filter null userAgent values at the Prisma query level (not in JS).
- Use UTC consistently for date grouping to avoid timezone shift issues.
- Fetch all sessions once for cumulative calculation -- do NOT run a query per day.
  </action>
