2. Add the reverse relation to the User model (after `submissionComments`):
   ```prisma

   ```

3. Add the new AuditLog model at the end of the schema file:
   ```prisma
   model AuditLog {
     id         String   @id @default(uuid())
     action     String
     entityType String   @map("entity_type")
     entityId   String   @map("entity_id")
     actorId    String   @map("actor_id")
     actor      User     @relation(fields: [actorId], references: [id])
     oldValue   String?  @map("old_value")
     newValue   String?  @map("new_value")
     metadata   Json?
     createdAt  DateTime @default(now()) @map("created_at")

     @@index([createdAt])
     @@index([actorId])
     @@index([entityId])
     @@map("audit_log")
   }
   ```

   Key conventions followed:
   - `@@map("audit_log")` for snake_case table name
   - `@map("snake_case")` on every camelCase field
   - `@default(uuid())` for ID
   - `@default(now())` for createdAt
   - NO `updatedAt` field (immutable model per AUDIT-02)
   - NO enum for action field (String per user decision)
   - `@default(false)` on mustChangePassword so existing users are unaffected
   - Three indexes on AuditLog: createdAt, actorId, entityId

4. Validate schema: `npx prisma validate`
5. Generate migration: `npx prisma migrate dev --name add_audit_log_and_user_fields`
6. Verify client generation: `npx prisma generate` (should succeed with new AuditLog type)
