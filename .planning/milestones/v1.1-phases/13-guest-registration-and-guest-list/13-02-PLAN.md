  <action>
Create GET endpoint for faculty-scoped, paginated guest list:

1. Auth: `const { authorized, user, error } = await requireRole(["MARKETING_COORDINATOR"])` -- return 403 if not authorized
2. Faculty scoping (copy pattern from coordinator submissions route):
   - `prisma.user.findUnique({ where: { id: user!.id }, select: { facultyId: true } })`
   - Return 403 "No assigned faculty" if `!dbUser?.facultyId`
3. Parse query params from `req.url`:
   - `page`: default 1, minimum 1
   - `pageSize`: default 10, whitelist [10, 25, 50]
   - `q`: optional search string, trimmed
   - Compute `skip = (page - 1) * pageSize`
4. Build where clause:
   ```
   { role: "GUEST", facultyId: dbUser.facultyId,
     ...(q && { OR: [
       { name: { contains: q, mode: "insensitive" } },
       { email: { contains: q, mode: "insensitive" } }
     ]})
   }
   ```
5. Parallel query: `Promise.all([prisma.user.count({ where }), prisma.user.findMany({ where, skip, take: pageSize, orderBy: { createdAt: "desc" }, select: { id: true, name: true, email: true, createdAt: true, faculty: { select: { name: true } } } })])`
6. Return `{ guests, total, page, pageSize }`
7. Wrap in try/catch, return 500 on error

Import from: `@/lib/auth-helpers`, `@/lib/prisma`, `next/server`
Follow the exact code pattern from 13-RESEARCH.md Guest List API Route section.
