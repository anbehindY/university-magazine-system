<task type="auto">
  <name>Task 1: Create registration API and email check endpoint</name>
  <files>app/api/register/route.ts, app/api/register/check-email/route.ts</files>
  <action>
Create two API route files:

**app/api/register/route.ts** -- POST endpoint for guest self-registration:
1. Parse request body: extract name, email, password, facultyId as trimmed strings
2. Validate all fields are present (return 400 if missing)
3. Validate facultyId exists via `prisma.faculty.findUnique({ where: { id: facultyId } })` -- return 400 "Invalid faculty" if not found
4. Check email uniqueness via `prisma.user.findFirst({ where: { email: { equals: email, mode: "insensitive" } } })` -- return 409 "Email already registered" if taken
5. Create account via `auth.api.signUpEmail({ body: { name, email, password } })`
6. Update user with HARDCODED role: `prisma.user.update({ where: { id: result.user.id }, data: { role: "GUEST", facultyId, emailVerified: true, mustChangePassword: false } })`
   - CRITICAL: NEVER read role from request body. Hardcode "GUEST".
7. Query coordinators: `prisma.user.findMany({ where: { role: "MARKETING_COORDINATOR", facultyId }, select: { email: true } })`
8. If coordinators found, fire-and-forget email: `sendMail({ to: coordinatorEmails, subject: "New guest registration: {name} -- {facultyName}", html/text with guest details and link to /coordinator/guests }).catch(console.error)` -- NO await
9. If no coordinators found, silently skip (no error)
10. Return `{ success: true }` with status 201
11. Wrap in try/catch, return 500 on unexpected errors

Import from: `@/lib/auth`, `@/lib/prisma`, `@/lib/mailer`, `next/server`

**app/api/register/check-email/route.ts** -- GET endpoint for email uniqueness:
1. Read `email` from searchParams, trim and lowercase
2. If no email, return `{ available: false }`
3. Query `prisma.user.findFirst({ where: { email: { equals: email, mode: "insensitive" } }, select: { id: true } })`
4. Return `{ available: !existing }`

Follow the exact code patterns from 13-RESEARCH.md Code Examples section.
